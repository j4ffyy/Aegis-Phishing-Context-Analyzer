## Key Empirical Findings & Methodological Boundary Conditions

1. **Training Distribution:**
   - The Random Forest and XGBoost models were trained on 1,000 synthetic feature vectors derived from parameterized distributions.
   - 5-fold cross-validation on this synthetic distribution achieved an F1-score of 1.0000 due to clear class separation in the synthetic parameters.

2. **Test Dataset Nature:**
   - The test dataset consists of 100 emails procedurally generated from structured template banks (GCash, BDO, BPI, Maya, Shopee, SSS, Taglish lures, wire fraud, and benign transactional/interpersonal emails).
   - No live LLM API (e.g., ChatGPT/Claude) was invoked dynamically during test sample generation; all emails were template-synthesized.
   - SPF and DKIM pass/fail statuses were supplied as synthetic binary fields (`spfPass`, `dkimPass`) rather than parsed from the live Gmail DOM.

3. **Active Subsystems in Offline Evaluation:**
   - **Layer 1 (Active):** Heuristic rules + Typosquatting + Tabular Ensemble (RF + XGBoost).

   - **Layer 3 (Neutralized):** Defaulted to neutral constant score $S_{behavioral} = 15$ due to absence of longitudinal client interaction telemetry.
   - **Layer 4 (Skipped):** VirusTotal network lookups were bypassed in offline mode.
